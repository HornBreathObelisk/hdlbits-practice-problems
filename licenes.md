## ❓ What Is HDLBits

| **Term** | **Description** |
|-----------|-----------------|
| **HDL** | Hardware Description Language |
| **Verilog** | Classic HDL |
| **SystemVerilog** | Modern HDL |
| **Combinational** | No memory |
| **Sequential** | Clocked logic |
| **FSM** | Finite state machine |

**Why use it?**
- ✅ Bite-sized exercises
- ✅ Instant feedback
- ✅ Verilog + SystemVerilog
- ✅ Browser-based
- ✅ Free guide

## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **Test fails silently** | Check reset and clock |
| **Wrong output width** | Match bit widths |
| **Combinational loop** | Check feedback |
| **FSM stuck** | Verify state transitions |
| **Syntax error** | Check Verilog reference |
| **Unknown module** | Check module name |
